# 🎨 img2palette

Turn images, GIFs and video into color palettes from 50+ popular themes — Catppuccin, Dracula, Nord and more. Interactive Rich TUI with EN/RU localization.

## Features

- **Single image** and **batch** modes
- **GIF & video** support (optional dependencies: `requirements-video.txt`)
- **50+ palettes** with categories and bilingual names (`name` / `name_ru`)
- First-run setup and friendly Rich menus
- Pure Python

## Quick start

```bash
pip install -r requirements.txt

# optional: video support
pip install -r requirements-video.txt

python main.py
```

Pick a palette theme, feed it an image — get a matching color scheme for your project.
